# 🪄 粉刷匠 (SiYuan Style Editor)

思源笔记原生主题不够个性化？想要微调排版却不会写 CSS？喜欢多个主题的特色功能，却无法让它们兼容并存？

“粉刷匠”是一款专为思源笔记用户打造的可视化、所见即所得的样式定制插件。通过图形化面板和直观的选项，无需一行代码，即可轻松微调正文排版和全局界面，打造只属于你的完美数字花园。

---

## 🎯 解决的问题与用户价值

在日常笔记和知识管理中，你可能常常遇到以下烦恼：
1. **定制门槛高**：想修改字体、字号、间距或标题样式，不得不学习并编写复杂的 CSS 代码。
2. **主题功能分裂**：想要 A 主题的“列表转看板”功能，又想要 B 主题的“毛玻璃顶栏”和 C 主题的“主动召回背诵功能”……但在思源中，你只能选择一个主题，无法兼得。
3. **缺乏即时反馈**：每次手写 CSS 片段都必须保存、刷新页面才能看效果，调整过程繁琐低效。
4. **正文与界面混淆**：有些修改只想针对正文排版（安全不伤眼），而有些想彻底改变软件界面布局。缺乏灵活的安全级别区分。

**「粉刷匠」彻底终结这些痛点：**
- **零代码门槛**：全图形界面（GUI）操作，滑块调数值，色板选颜色。
- **融百家之长**：将社区明星主题中最受欢迎的黑魔法特性深度融合，供你自由挑选、开启和拼装。
- **所见即所得**：在右侧面板点击色板或拖动滑块，左侧编辑器里的文档样式**立刻渲染，毫秒级生效**。
- **正文安全与全屋改造分离**：预置安全隔离机制，你可以只安全修改正文排版，也可以开启全界面深度定制，彻底规避界面错乱风险。

## 🌟 核心功能与使用场景

### ✍️ 极致舒适的阅读与写作（正文排版）
长时间面对屏幕，舒适的排版对视力和专注力至关重要。
*   **基础排版微调**：自由调节基础字号、行高、字间距、编辑器宽度，打破主题默认限制。
*   **标题优雅装饰**：为 H1-H6 标题开启精美的前缀几何指示器（点数代表标题级别），定制标题上下间距，让文章结构一目了然。
*   **大纲与目录增强**：开启大纲自动编号，即使主题不支持，也能轻松展示清晰的层级。
*   **清晰引导线**：支持开启列表折叠提示线和引导线，在处理多级复杂大纲时不再迷失。

### 🧠 主动召回与高效背诵（学生/考研党福音）
为备考者和需要复习核心概念的用户量身定制。
*   **划词智能挖空 (`activeRecallHide`)**：将标记（Mark）或特定格式文本一键“挖空”（高斯模糊或变黑），在阅读或背诵时充当临时遮罩。
*   **悬停即显**：只需将鼠标悬停在挖空块上，真实文字立刻清晰浮现，移开后恢复遮罩，完美模拟物理卡片背诵体验。

### 📊 列表变身黑魔法（卡片看板与思维导图）
告别单调冗长的层级列表，换个视角看知识。
*   **列表转看板**：给无序列表简单设置，即可将其横向平铺渲染为精致的“看板卡片”，非常适合管理任务流程（To-Do）或做维度对比。
*   **列表转脑图**：自动将列表转换为带有分支线条、水平展开的“思维导图”效果，快速梳理知识脉络。

### 🎨 全局视觉与氛围感打造（全屋改造）
打破千篇一律的界面，营造沉浸式工作空间。
*   **毛玻璃/亚克力顶栏**：为顶栏和页签栏注入高级毛玻璃模糊动效，使软件质感更通透、更 Premium。
*   **自定义编辑器背景**：支持为编辑器区域添加渐变色、半透明磨砂或自定义背景图片，营造属于你自己的工作氛围。
*   **紧凑界面模式**：一键开启布局紧凑模式，收窄顶栏、Dock 栏和页签栏，把更多屏幕空间留给创作。
*   **彩色文档树**：为侧边栏文档树注入渐变或彩色区块，帮你的知识库“分门别类”。

### 🌈 智能颜色提取与回填
*   **取色回填**：能够自动从当前打开的文档中提取出显式使用的颜色，并回填到编辑面板的快捷色板中，方便你实现配色方案的统一。

## 🚀 快速上手

1. **启用插件**：在思源笔记“设置 -> 插件 -> 集市”中搜索并安装启用“粉刷匠”。
2. **打开面板**：在软件右侧的 Dock 栏中找到粉刷匠图标，点击展开定制面板。
3. **自由搭配**：
   - 切换“前景色/背景色”进行快速改色；
   - 在排版、元素、全局外观等分类下，按需开启特定功能（如开启“列表引导线”、“标题几何指示器”）；
   - 拖动滑块调节尺寸、间距或选择字体。
4. **即时预览与保存**：点击色板或切换开关，左侧文档会**立即改变**。满意的配置会自动持久化保存，即使重启思源笔记也依然生效。

## 💡 为什么选择“粉刷匠”？

| 维度 | 直接改 CSS | 使用单一主题 | 使用“粉刷匠” |
| :--- | :--- | :--- | :--- |
| **技术要求** | 需要掌握 CSS 选择器与样式语法 | 零基础，但无法个性化细节 | **零基础**，全图形化界面操作 |
| **生效速度** | 需要保存、重载，过程繁杂 | 全局应用，不可调整 | **所见即所得**，毫秒级即时生效 |
| **灵活性** | 高，但容易写错导致排版崩塌 | 只能接受该主题的固定设计 | **自由挑选与拼装**各主题的特色功能 |
| **配置安全** | 容易污染全局样式，难以恢复 | 无法安全隔离正文和界面 | 提供**正文安全**防护，配置一键还原 |
