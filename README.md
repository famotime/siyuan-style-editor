# 文档样式编辑器

一个面向思源笔记的模板驱动样式插件。

## 功能

- 将当前文档绑定为样式模板文档。
- 在模板文档中通过颜色板实时预览 H1-H6 与加粗文本的显示效果。
- 从模板文档读取现有样式，并将结果注入到全部文档显示中。
- 样式配置持久化保存，重启思源后继续生效。

## 使用方式

1. 打开样式模板文档，推荐使用 `docs/思源笔记样式效果测试预览文档.sy` 对应的示例内容。
2. 在右侧 Dock 打开“文档样式编辑器”。
3. 点击“将当前文档设为样式模板”。
4. 选择 H1-H6 或“加粗文本”目标，再点击颜色板。
5. 如果模板文档本身已有样式，点击“从当前模板读取样式”导入。

## 开发命令

```bash
npm install --legacy-peer-deps
npm test
npm run build
```
